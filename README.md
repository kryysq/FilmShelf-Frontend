# FilmShelf Frontend

Мінімалістичний фронтенд для демонстрації роботи CORS та отримання даних із REST API бекенду FilmShelf.

## Як запустити проєкт

1. **Запуск бекенду:**
   Переконайтеся, що ваш бекенд на Django запущений та працює на `http://127.0.0.1:8000`.

2. **Запуск фронтенду:**
   Оскільки це чистий HTML/JS, ви можете просто відкрити файл `index.html` у будь-якому браузері. 
   
   Або, щоб імітувати роботу на іншому порту (для тесту CORS), відкрийте термінал у папці фронтенду та виконайте:
   `python -m http.server 3000`
   Після цього перейдіть за адресою `http://localhost:3000`.

3. **Використання:**
   Натисніть кнопку "Отримати список фільмів з бекенду", щоб зробити крос-доменний запит та побачити каталог.
